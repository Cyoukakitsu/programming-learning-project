# pi-study-memo

PI Agent アーキテクチャ設計を学ぶための学習記録リポジトリです。TypeScript でわずか約100行の汎用エージェントを実装し、PI-Agent 的なアーキテクチャ設計とその実践を通じて理解を深めることを目的としています。

## 目的

- PI Agent のアーキテクチャ設計思想を学ぶ
- TypeScript で最小限の汎用エージェント（100行程度）を実装する
- 類 PI-Agent アーキテクチャの設計パターンと実践を記録する

## 学習テーマ

- エージェントの基本ループ（観測 → 思考 → 行動）
- ツール呼び出し（Tool Use）の設計
- 最小構成でのプランニング・実行フロー
- シンプルな実装から見えるアーキテクチャの本質

## プロジェクト構成

```
.
├── apps/            # アプリケーション（実装コード）
├── packages/         # 共有パッケージ・ライブラリ
├── package.json
├── pnpm-workspace.yaml
└── tsconfig.json
```

pnpm workspace によるモノレポ構成を採用しています。

## セットアップ

```bash
pnpm install
```

## TypeScript ビルド

```bash
pnpm exec tsc
```

- アーキテクチャ設計に関する学習メモを追記
- 実践を通じた改善点・気づきの記録
