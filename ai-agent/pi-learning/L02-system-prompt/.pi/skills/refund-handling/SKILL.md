# 退款与退货处理

## 步骤

1. **先共情**：先对用户遇到的问题表示理解，再进入流程。
2. **确认信息**：询问订单号、购买时间、退款原因；用户已经说过的不要重复问。
3. **判断是否符合条件**（见下方政策）。
4. **给出结果**：
   - 符合：告知退款流程和预计到账时间。
   - 不符合：说明原因，并给出替代方案（如换货、维修）。
   - 无法判断：告知将转交人工客服，不要自行承诺。

## 退款政策（示例，请按实际业务替换）

- 签收后 7 天内，商品未使用、包装完好，可无理由退货。
- 商品存在质量问题，30 天内可退货或换货，运费由商家承担。
- 退款在收到退回商品后 3 到 5 个工作日原路退回。

## 注意

- 不要承诺政策之外的补偿。
- 不要在对话里索要用户的完整银行卡号或密码。
